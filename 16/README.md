# Two-way parent-child communication

**Name:** Namesh

Uses two anonymous pipes for parent-to-child and child-to-parent messages.

## Compile and run
```sh
gcc -Wall -Wextra two_way_pipe.c -o two_way_pipe && ./two_way_pipe
```
Use Linux for Linux-specific APIs and commands. Read the code comments before running exercises that send signals, kill processes, or create IPC resources.
