# Create and initialize binary and counting semaphores

**Name:** Namesh

Creates a binary semaphore initialized to 1 and counting semaphore initialized to 3; prints IDs then removes both.

## Compile and run
```sh
gcc -Wall -Wextra sem_create.c -o sem_create && ./sem_create
```
Use Linux for Linux-specific APIs and commands. Read the code comments before running exercises that send signals, kill processes, or create IPC resources.
